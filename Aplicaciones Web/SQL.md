
## SQL

**¿Qué es?**  
SQL (Structured Query Language) es un lenguaje utilizado para consultar, modificar y administrar información almacenada en bases de datos relacionales.

**¿Dónde lo encuentro?**  
En aplicaciones web, sistemas empresariales, APIs y servidores de bases de datos que utilizan sistemas como MySQL, PostgreSQL, Microsoft SQL Server u Oracle Database.

**¿Por qué me afecta?**  
Una implementación insegura puede permitir que entradas controladas por usuarios sean interpretadas como consultas SQL, exponiendo o modificando información sensible.

**¿Cómo se soluciona?**  
Utilizando consultas parametrizadas, validación de entradas, cuentas con privilegios mínimos y controles adecuados de acceso a la base de datos.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede intentar manipular consultas mediante técnicas de SQL Injection para acceder, modificar o eliminar información de la base de datos.
