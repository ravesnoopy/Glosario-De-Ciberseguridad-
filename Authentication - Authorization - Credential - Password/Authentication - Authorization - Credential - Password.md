
## Authentication

**¿Qué es?**  
Authentication es el proceso mediante el cual un sistema verifica la identidad de un usuario, dispositivo o servicio antes de permitirle acceder.

**¿Dónde lo encuentro?**  
En formularios de inicio de sesión, aplicaciones web, VPN, sistemas operativos, APIs y servicios que requieren verificar la identidad de sus usuarios.

**¿Por qué me afecta?**  
Una autenticación débil puede permitir accesos no autorizados, robo de cuentas y compromiso de información o recursos protegidos.

**¿Cómo se soluciona?**  
Utilizando contraseñas robustas, MFA, almacenamiento seguro de credenciales, controles contra intentos automatizados y mecanismos de autenticación adecuados.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede intentar obtener o adivinar credenciales mediante phishing, fuerza bruta, password spraying, credential stuffing u otras técnicas para acceder a una cuenta.

## Authorization

**¿Qué es?**  
Authorization es el proceso mediante el cual un sistema determina qué recursos o acciones puede utilizar un usuario después de haber sido autenticado.

**¿Dónde lo encuentro?**  
En aplicaciones, APIs, sistemas operativos, bases de datos, servicios cloud y otros sistemas que asignan permisos o roles a usuarios y cuentas.

**¿Por qué me afecta?**  
Una autorización incorrecta puede permitir que un usuario acceda, modifique o elimine información y recursos que no debería poder utilizar.

**¿Cómo se soluciona?**  
Aplicando mínimo privilegio, controles de acceso basados en roles o atributos y verificando los permisos en el servidor para cada solicitud.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede explotar fallos de autorización para acceder a recursos de otros usuarios, modificar información o ejecutar acciones restringidas.

## Credential

**¿Qué es?**  
Una Credential es cualquier información utilizada para demostrar una identidad y obtener acceso a un sistema o recurso, como una contraseña, clave, token o certificado.

**¿Dónde lo encuentro?**  
En cuentas de usuario, sistemas operativos, aplicaciones, gestores de credenciales, APIs, servicios cloud y mecanismos de autenticación.

**¿Por qué me afecta?**  
Una credencial comprometida puede permitir que un atacante se haga pasar por un usuario legítimo y acceda a recursos protegidos.

**¿Cómo se soluciona?**  
Protegiendo las credenciales, aplicando mínimo privilegio, utilizando MFA, evitando su reutilización y revocándolas o rotándolas cuando exista sospecha de compromiso.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede robar, descubrir o reutilizar una credencial para autenticarse como la víctima y acceder a sistemas o información sin autorización.

## Password

**¿Qué es?**  
Una Password es una cadena secreta utilizada como factor de autenticación para demostrar que una persona conoce un secreto asociado con una cuenta.

**¿Dónde lo encuentro?**  
En cuentas de usuarios, sistemas operativos, aplicaciones web, servicios cloud, VPN y otros sistemas protegidos mediante autenticación.

**¿Por qué me afecta?**  
Una contraseña débil, reutilizada o comprometida puede permitir que un atacante tome control de una cuenta.

**¿Cómo se soluciona?**  
Utilizando contraseñas largas y únicas, gestores de contraseñas, MFA y mecanismos seguros de almacenamiento que utilicen hashing apropiado.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede obtenerla mediante phishing, filtraciones, malware, ataques de fuerza bruta, password spraying o credential stuffing para acceder a la cuenta.
