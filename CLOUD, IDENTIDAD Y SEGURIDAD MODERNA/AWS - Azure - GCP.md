
## AWS

**¿Qué es?**  
AWS (Amazon Web Services) es una plataforma de computación en la nube que proporciona servicios como almacenamiento, redes, bases de datos, máquinas virtuales y gestión de identidades.

**¿Dónde lo encuentro?**  
En infraestructuras cloud utilizadas por organizaciones para alojar aplicaciones, servicios, datos y recursos empresariales.

**¿Por qué me afecta?**  
Una configuración incorrecta de recursos, identidades o permisos puede exponer información sensible o permitir acceso no autorizado a la infraestructura.

**¿Cómo se soluciona?**  
Aplicando mínimo privilegio, MFA, segmentación, cifrado, configuraciones seguras y monitoreo continuo de cuentas y recursos cloud.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede aprovechar credenciales comprometidas, permisos excesivos o recursos configurados incorrectamente para acceder a datos, modificar infraestructura o mantener persistencia.

## Azure

**¿Qué es?**  
Azure es una plataforma de computación en la nube de Microsoft que ofrece servicios de infraestructura, aplicaciones, almacenamiento, redes, bases de datos e identidad.

**¿Dónde lo encuentro?**  
En organizaciones que utilizan servicios cloud de Microsoft para alojar aplicaciones, administrar infraestructura y almacenar información empresarial.

**¿Por qué me afecta?**  
Una configuración insegura de identidades, permisos o recursos puede permitir accesos no autorizados y exposición de información.

**¿Cómo se soluciona?**  
Aplicando mínimo privilegio, MFA, políticas de acceso, segmentación, cifrado y monitoreo de actividades e identidades dentro del entorno cloud.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede utilizar credenciales comprometidas, permisos excesivos o configuraciones vulnerables para acceder a recursos, datos y servicios de la organización.

## GCP

**¿Qué es?**  
GCP (Google Cloud Platform) es una plataforma de computación en la nube de Google que proporciona servicios de infraestructura, almacenamiento, redes, bases de datos, aplicaciones e identidad.

**¿Dónde lo encuentro?**  
En organizaciones que utilizan infraestructura cloud de Google para ejecutar aplicaciones, almacenar datos y administrar servicios empresariales.

**¿Por qué me afecta?**  
Una mala configuración de permisos, identidades o recursos puede provocar exposición de datos o acceso no autorizado a servicios cloud.

**¿Cómo se soluciona?**  
Aplicando mínimo privilegio, MFA, gestión segura de identidades, cifrado, segmentación y monitoreo continuo de recursos y actividades.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede aprovechar credenciales comprometidas, permisos excesivos o recursos expuestos para acceder a información, modificar servicios o ampliar su presencia dentro del entorno cloud.
