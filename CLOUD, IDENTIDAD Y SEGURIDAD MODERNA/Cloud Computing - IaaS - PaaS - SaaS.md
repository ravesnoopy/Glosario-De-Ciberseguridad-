
## Cloud Computing

**¿Qué es?**  
Cloud Computing es un modelo que permite utilizar recursos informáticos como servidores, almacenamiento, redes y aplicaciones a través de Internet, sin necesidad de administrar directamente toda la infraestructura física.

**¿Dónde lo encuentro?**  
En servicios empresariales, aplicaciones web, almacenamiento en línea, plataformas de desarrollo y sistemas que utilizan infraestructura proporcionada por proveedores cloud.

**¿Por qué me afecta?**  
Una configuración incorrecta de identidades, permisos, redes o almacenamiento puede exponer información y recursos a usuarios no autorizados.

**¿Cómo se soluciona?**  
Aplicando mínimo privilegio, MFA, cifrado, segmentación, configuraciones seguras y monitoreo continuo de los recursos cloud.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede aprovechar credenciales comprometidas, permisos excesivos o recursos expuestos para acceder a datos, ejecutar recursos o desplazarse dentro del entorno cloud.

## IaaS

**¿Qué es?**  
IaaS (Infrastructure as a Service) es un modelo cloud que proporciona recursos de infraestructura como máquinas virtuales, almacenamiento y redes, mientras el cliente administra gran parte del sistema operativo y las aplicaciones.

**¿Dónde lo encuentro?**  
En entornos donde una organización utiliza servidores virtuales, redes y almacenamiento proporcionados por un proveedor cloud para ejecutar sus propios sistemas.

**¿Por qué me afecta?**  
El cliente mantiene responsabilidades de seguridad sobre sistemas operativos, aplicaciones, configuraciones de red y controles de acceso, por lo que una mala configuración puede generar vulnerabilidades.

**¿Cómo se soluciona?**  
Aplicando hardening, gestión de parches, mínimo privilegio, segmentación de red, controles de acceso y monitoreo de las máquinas y recursos virtuales.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede explotar una máquina virtual vulnerable, credenciales comprometidas o configuraciones de red inseguras para acceder a recursos adicionales.

## PaaS

**¿Qué es?**  
PaaS (Platform as a Service) es un modelo cloud que proporciona una plataforma administrada para desarrollar, ejecutar y desplegar aplicaciones sin que el cliente tenga que administrar directamente toda la infraestructura subyacente.

**¿Dónde lo encuentro?**  
En plataformas utilizadas por desarrolladores para desplegar aplicaciones, APIs y servicios sin administrar directamente los servidores físicos o gran parte del sistema operativo.

**¿Por qué me afecta?**  
Una aplicación, identidad o configuración insegura dentro de la plataforma puede provocar exposición de datos o acceso no autorizado a otros recursos.

**¿Cómo se soluciona?**  
Aplicando controles de identidad y acceso, gestión segura de secretos, validación de aplicaciones, configuración segura y monitoreo de los servicios desplegados.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede explotar vulnerabilidades de una aplicación desplegada o aprovechar credenciales y secretos expuestos para acceder a recursos asociados con la plataforma.

## SaaS

**¿Qué es?**  
SaaS (Software as a Service) es un modelo cloud en el que el proveedor ofrece una aplicación lista para utilizar a través de Internet, mientras administra gran parte de la infraestructura y plataforma.

**¿Dónde lo encuentro?**  
En aplicaciones empresariales como correo electrónico, colaboración, almacenamiento, gestión de clientes y otras herramientas utilizadas mediante navegador o aplicaciones cliente.

**¿Por qué me afecta?**  
Una cuenta comprometida, configuración incorrecta o permisos excesivos pueden permitir el acceso a información empresarial y recursos sensibles.

**¿Cómo se soluciona?**  
Utilizando MFA, mínimo privilegio, políticas de acceso, gestión adecuada de cuentas, monitoreo de actividad y controles de seguridad proporcionados por el servicio.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede comprometer una cuenta mediante phishing o credenciales robadas y utilizarla para acceder a información, enviar mensajes maliciosos o aprovechar los permisos disponibles.
