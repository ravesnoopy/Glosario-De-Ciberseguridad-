# PowerShell

**¿Qué es?**  
PowerShell es una shell y plataforma de automatización de Microsoft que permite ejecutar comandos, scripts y administrar sistemas mediante objetos y APIs.

**¿Dónde lo encuentro?**  
En sistemas Windows, servidores y entornos empresariales donde se utiliza para administración y automatización.

**¿Por qué me afecta?**  
Es una herramienta legítima con amplias capacidades administrativas que también puede ser abusada para ejecutar acciones maliciosas utilizando componentes ya presentes en el sistema.

**¿Cómo se soluciona?**  
Monitoreando su ejecución, registrando actividad relevante, aplicando políticas de seguridad y restringiendo su uso administrativo según el principio de mínimo privilegio.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede abusar de PowerShell para ejecutar comandos y scripts, recopilar información, modificar configuraciones o interactuar con otros componentes del sistema.

# CMD

**¿Qué es?**  
CMD es el intérprete de comandos de Windows que permite ejecutar comandos y programas mediante una interfaz de línea de comandos.

**¿Dónde lo encuentro?**  
En sistemas Windows, servidores y estaciones de trabajo.

**¿Por qué me afecta?**  
Permite realizar numerosas tareas administrativas y puede ser utilizado para ejecutar comandos después de que un atacante obtiene acceso al sistema.

**¿Cómo se soluciona?**  
Aplicando mínimo privilegio, monitoreando procesos y líneas de comandos y restringiendo su uso cuando no sea necesario.

**¿Cómo lo usaría un atacante en mi contra?**  
Puede utilizar CMD para ejecutar comandos, iniciar programas, modificar configuraciones y automatizar actividades dentro de un sistema comprometido.
